### 🧠 The Vision
This isn't just a portfolio; it’s a digital reflection of my technical journey. I wanted to build a space that felt **fluid, intentional, and high-performance**. It serves as a playground for me to test out new frontend patterns and showcase my project library.

### ⚡ Technical Highlights
- **Performance:** Optimized for Core Web Vitals with Next.js Image optimization and code splitting.
- **Type Safety:** Built entirely with TypeScript to ensure a robust and scalable codebase.
- **Aesthetics:** Styled with Tailwind CSS for a modern, minimalist look, enhanced by Framer Motion for organic interactions.
- **Responsive:** Designed with a mobile-first approach, ensuring the "vibe" stays intact on any screen size.

### 🛠️ Architecture
```text
├── 📂 components   # Atomic UI components
├── 📂 pages        # File-based routing & SSR logic
├── 📂 public       # High-res assets & branding
├── 📂 styles       # Global design tokens & Tailwind config
└── 📂 types        # Centralized TypeScript definitions
```
