This post is a reference template for future deepdive entries. Keep it short, structured, and visual when helpful.

## Post Structure

1. Start with a strong opening sentence that explains the problem.
2. Add a short section for the core idea or method.
3. Use bullet points or numbered lists for key takeaways.
4. Include a practical example or diagram if it helps explain the concept.

## Markdown Tips

- Use `#` headers to create clear sections.
- Use `**bold**` for emphasis and `*italics*` for softer cues.
- Use fenced code blocks for code snippets.
- Add images by placing them in the public folder and linking to them.

## Writing Reminder

Aim for clarity over cleverness. A deepdive post should feel easy to scan and useful to revisit.
