Combining genetic programming with LLM mutations creates an automated loop that designs algorithmic answers.

## The Evolution Loop

1. **Initialize** a population of candidate solutions
2. **Evaluate** fitness against target specifications
3. **Mutate** using LLM-guided code transformations
4. **Select** survivors and repeat

By leveraging extremely high-throughput APIs (like Groq) as mutation selectors, populations of functional algorithms evolve to meet complex specs without human code inputs.
